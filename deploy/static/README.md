# Quantix — AI-powered science & maths lab (Lite)

Free tools for students, in English and हिन्दी — all running in your browser:

* **Formula Library** — 1,022 formulas, PDFs and a step-by-step calculator (real Python + SymPy in the browser)
* **Periodic Table** with molar-mass calculator, **Physics Lab** simulations, **Equation Solver** (type an equation),
  **Unit Converter**, **Graph Plotter**

Photo AI (shape recognition, measuring from photos, reading handwriting) is in the full version, free to run on your own
PC: [GitHub](https://github.com/Abhishek7880/quantix-AI-powered-science-maths-lab).
